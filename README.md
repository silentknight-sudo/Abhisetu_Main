# Abhiyantri Work Profile

Work profile website for **Abhiyantri Setu**: interior design and property painting services in Greater Noida.

- 3D scroll tour of room models (Three.js)
- 3D photo carousel of project images
- Contact details and WhatsApp chat button

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Publish free on GitHub Pages

Repository Settings → Pages → Source: `main` branch, `/ (root)`.
